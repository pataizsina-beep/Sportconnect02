SportConnect — Compact dashboard layout

WHAT CHANGED
- After login, the left hero panel becomes a short horizontal banner.
- “Your next great match starts here.” appears on one line on desktop.
- The dashboard uses the full page width and displays service cards in three columns on wide screens, two on tablets, and one on small phones.
- The original split login/sign-up screen remains unchanged.
- The current messaging diagnostic app.js is preserved; this is a visual/layout change only.

INSTALL
1. Back up your current index.html, app.js, and style.css.
2. Copy the three files from this package into the same folder used by Live Server.
3. Replace all three files together.
4. Refresh with Ctrl+F5.

No PocketBase migration or API-rule changes are required.
